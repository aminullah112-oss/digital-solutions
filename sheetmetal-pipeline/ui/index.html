Sheet Metal Job Builder

Spec sheet builder + validator for the Excel → SheetMetal → DXF pipeline

What this page does on its own vs. with a backend. This page runs in your browser — GitHub Pages is static hosting, it has no server of its own. Without a backend configured below, it validates dimensions against the exact same manufacturability rules and bend-allowance math as the Python pipeline (bracket_model.py), looks up K-factor from the live kfactor_table.json, and builds a real .xlsx to hand to freecadcmd scripts/run_batch.py yourself. With a backend URL configured (see backend/README.md to deploy one), the "Generate real part" button below actually calls it and downloads a real STEP + DXF pair — the backend runs the identical build_bracket() this whole pipeline has used since Stage 2.
