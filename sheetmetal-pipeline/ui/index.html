Sheet Metal Job Builder

Spec sheet builder + validator for the Excel → SheetMetal → DXF pipeline

What this page actually does, and doesn't. This runs in your browser only — there is no server behind it. It cannot run FreeCAD, and it will not generate STEP or DXF files. What it does do for real: validate a part's dimensions against the exact same manufacturability rules and bend-allowance math as the Python pipeline (bracket_model.py), look up K-factor from the same kfactor_table.json the batch script uses, and let you build a real .xlsx file with the correct columns to hand to freecadcmd scripts/run_batch.py — see the pipeline README for that step. Generating the actual 3D part and flat pattern always requires running that script somewhere FreeCAD is installed; no static site can do that part.
