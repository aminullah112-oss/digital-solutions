## Revision convention

- **Revision** is the package (design basis) revision. It changes when the master configuration changes.
- **Issue** (P1, P2, ...) is the document's own preliminary issue. It changes when the document is reissued. Neither is an approval.
- **Related** lists the documents that must be read with this one (the workbook for a specification, the methodology for a workbook, and so on).
- The machine-readable register is `MASTER_INDEX.csv`; the package manifest (`MANIFEST.json`) carries the same ids, revisions and a SHA-256 hash per file.
